# Air OS 2.5

- Voice automatically answers after speech ends, including while the microphone button is held. “Uhh”, “um” and “erm” are ignored; filler-only recordings continue listening.
- Downloading and Installing appear on App Store tiles, with a percentage when the server supplies a download size. Failed downloads show an error and can be retried.
- Hold OK for 0.7 seconds on a Home app to open its menu. Select Remove to remove an installed app, or hide a built-in app. Settings and App Store stay available. Restore built-in apps in Settings.
- Centred app rows, larger icons, visible labels and a clear initials icon if artwork cannot load.

Install on the TV using Settings → System → Software update. No API key change is needed. Air Family and the Kitchen APK are unchanged.
