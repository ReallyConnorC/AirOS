Making an .atv file

An .atv file is a zip file with a different ending. At its top level it has a manifest.json, an icon, and your app's web pages. Air OS opens start full screen; the remote's arrow keys, OK (Enter) and Back (Escape) arrive as normal key presses, and the Home button always returns to Air OS.

{
  "id": "com.yourname.weather",
  "name": "Weather",
  "version": "1.0.0",
  "description": "Today's forecast for your town.",
  "icon": "icon.png",
  "color": "#1a6bd6",
  "start": "index.html"
}

Instead of start, a manifest can give "url": "https://…" to open a website made for TVs. IDs are lowercase letters, numbers, dots and dashes, and belong to whoever uploads them first. Raise version for each update. Files can be up to 50 MB.

Apps run in their own sandbox: they can use the internet, but not the TV's settings, Wi‑Fi, account or files.

Download an example app (hello-world.atv), rename it to .zip to look inside.
